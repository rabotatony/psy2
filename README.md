# PSY2 · מנוע פסיי-טראנס חי

**🔗 חי עכשיו: https://psy2.pages.dev**

מנוע פסיי-טראנס שנבנה מהיסוד לסאונד מקצועי — לא דמו, לא טלאים.

## מה זה

אינסטרומנט פסיי-טראנס בדפדפן שמייצר מוזיקה חיה, מגוונת והרמונית — למתחילים (לחיצה אחת) ולמקצוענים (שליטה מלאה).

## פיצ'רים

- **מנוע סינתזה חדש** — Wavetable + FM (טימברים עשירים, לא אוסצילטורים בסיסיים) + מאסטרינג multi-band
- **10 סגנונות מובחנים** — FULL-ON, DARK, PROG, ACID, GOA, NIGHT, CHILL, AMBIENT, PSYCHILL, DUB — כל אחד עם זהות צליל אמיתית (timbre + סולם + פרוגרסיה + BPM)
- **Sequencer הרמוני 32 צעדים** — בס/ליד עוקבים אחר פרוגרסיית אקורדים, עם micro-timing (נשמה)
- **AUTO חכם** — מבנה מוזיקלי אמיתי: intro → build → drop → break → climax
- **🎧 מצב DJ אינסופי** — מתפתח אוטומטית בין סגנונות עם מעברי filter-sweep חלקים, בלי סוף
- **מרחב** — ping-pong delay + reverb (עומק אמיתי)
- **📊 MEASURE** — ולידציה אובייקטיבית: LUFS / Crest / איזון תדרים לכל סגנון
- **מקרואים מקצועיים** — DRIVE / CUTOFF / SPACE / PUMP (שליטה עמוקה בסאונד)

## איך משתמשים

1. פתח https://psy2.pages.dev
2. לחץ **▶ PLAY** — מוזיקה חיה מיד
3. בחר סגנון — כל סגנון נשמע אחרת
4. **🎧 DJ** — סט אינסופי שמתפתח לבד
5. **📊 MEASURE** — מספרי איכות אובייקטיביים

## ארכיטקטורה

| קובץ | תפקיד |
|---|---|
| `js/engine.js` | מנוע סינתזה (wavetable/FM) + מאסטרינג + מקרואים |
| `js/core.js` | סגנונות, סולמות, פרוגרסיות |
| `js/music.js` | sequencer הרמוני + AUTO + DJ |
| `js/validate.js` | ולידציה אובייקטיבית (LUFS/crest/תדרים) |
| `js/app.js` | UI |
